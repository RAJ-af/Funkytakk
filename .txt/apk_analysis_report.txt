3. RELEASE AAB (ANDROID APP BUNDLE) & USER DOWNLOAD SIZE
--------------------------------------------------------------------------------
In an Android App Bundle (.aab), Google Play automatically delivers split APKs 
tailored specifically to each user's device architecture:

- Universal .aab File Size: ~48 - 55 MB
- User Download Size on Play Store: ~22 - 28 MB!
  (The user's device only receives their specific ABI, e.g., arm64-v8a (40 MB uncompressed,
   ~14 MB compressed), along with minified classes.dex (~4.5 MB compressed) and 
   shrunk resources (~3 MB compressed)).


--------------------------------------------------------------------------------
4. HOW TO KEEP ONLY arm64-v8a FOR TESTING APKS & ESTIMATED SIZE SAVINGS
--------------------------------------------------------------------------------
To generate a lightweight testing APK for real devices, add abiFilters to 
app/build.gradle.kts inside defaultConfig or the debug build type:

Option A: Global in defaultConfig (app/build.gradle.kts)
```kotlin
android {
    defaultConfig {
        ...
        ndk {
            abiFilters += listOf("arm64-v8a")
        }
    }
}
```

Option B: Debug only (recommended so release builds can still support all devices)
```kotlin
android {
    buildTypes {
        debug {
            ndk {
                abiFilters += listOf("arm64-v8a")
            }
        }
    }
}
```

Size Savings Achieved:
- armeabi-v7a eliminated: -28.85 MB
- x86 eliminated:         -31.89 MB
- x86_64 eliminated:      -32.67 MB
----------------------------------------------------
TOTAL NATIVE SAVINGS:     -93.41 MB uncompressed!

This brings the uncompressed native footprint down from 133.37 MB to 39.97 MB, 
cutting testing APK download size by more than 50% (down to ~40-50 MB).

5. TOP 10 LARGEST COMPONENTS IN THE APP (EXPLAINING THE ~131MB+ BASE)
--------------------------------------------------------------------------------
The reason the base is >131 MB is because universal builds duplicate native C++ 
binaries 4 times (for 4 CPU ABIs), combined with full multi-DEX debug code:

1. Agora Core RTC SDK (libagora-rtc-sdk.so)
   - Size: 17.1 MB per ABI x 4 ABIs = ~63.5 MB total
   - Purpose: Real-time audio engine, packet transport, codec encoding/decoding.

2. Multi-DEX Bytecode (classes.dex to classes18.dex in debug)
   - Size: ~95.3 MB uncompressed
   - Purpose: Jetpack Compose, Material 3, Firebase BOM, Coil, ExoPlayer, Room, Retrofit.
   - Note: R8 minification in release reduces this by ~85%.

3. Agora Lip-Sync & Acoustic Extensions (libagora_lip_sync_extension.so, AI Echo)
   - Size: ~6.7 MB per ABI = ~22.5 MB total
   - Purpose: Neural noise suppression and audio avatar lip-sync filters.

4. Agora Spatial Audio Extension (libagora_spatial_audio_extension.so)
   - Size: ~4.4 MB per ABI = ~16.9 MB total
   - Purpose: 3D spatial directional audio processing.

5. SQLCipher Database Security Engine (libsqlcipher.so)
   - Size: ~3.5 MB per ABI = ~12.8 MB total
   - Purpose: 256-bit AES encrypted SQLite database for secure local chats and vault.

6. Agora Media Decoder Engine (libagora-ffmpeg.so)
   - Size: ~2.8 - 3.3 MB per ABI = ~11.3 MB total
   - Purpose: Audio codec transcoding support.

7. Application Drawables & Graphic Resources (res/drawable*)
   - Size: 15.75 MB uncompressed
   - Purpose: Room themes, VIP badges, gift animations, custom avatar frames, and banners.

8. Agora Audio Beauty Extension (libagora_audio_beauty_extension.so)
   - Size: ~1.95 MB per ABI = ~7.0 MB total
   - Purpose: Voice pitch modulation and beautification filters.

9. Agora Audio Codec Libraries (libagora-fdkaac.so, libagora-soundtouch.so, libaosl.so)
   - Size: ~1.6 MB per ABI = ~6.4 MB total
   - Purpose: AAC hardware encoding/decoding and pitch/tempo manipulation.

10. Compiled Resource Table (resources.arsc)
    - Size: 1.01 MB
    - Purpose: Resource indexing table for thousands of string IDs, styles, and color keys.
